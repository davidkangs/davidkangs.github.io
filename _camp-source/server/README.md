# AI팀 가을 단합대회

2026-10-09–10, 대둔산 캠핑랜드 D5·D6 및 D존 중앙 카라반 두 동.

모바일 세로 행사 안내: 공식 사진, 스크롤 확대 배치도, 차량 진입 개략 안내, 일정, 금산 날씨, 실제 위치 지도, 주변 시설, 연구 근거, 식사 선택과 공동 장보기.

## 저장
D1 `DB`: shopping 및 meals. 개별 식사 수정은 HttpOnly 세션 쿠키로 연결되고 실제 내용은 D1에 보존된다. 공개 결과는 이름 없는 메뉴 집계, 전체 성인 식사 수량, 이름 없는 식사 메모다. 사용자에게 메모 공유 범위를 입력란 아래 명시한다. 장보기 수량·메모·준비 상태는 함께 수정한다. 손님별 이름과 자녀 수는 수집·표시하지 않는다.

## 확인 중인 사항
카라반 동번호·현재 사진·난방·침구·조리기구, D존 내부 최종 차량 진입 및 주차칸, 추가차량 주차, 우천식사공간, 실제 자동차 거리·소요시간. 기존 D존 사진의 중앙 공터를 현재 주차장으로 간주하지 않는다. 지도상의 별도 카라반존은 우리 예약으로 표시하지 않는다.

## 확인
TypeScript 및 Cloudflare Worker 빌드. 내부 미리보기에서 식사 저장/재열기, 장보기 추가/재열기, 390px iframe 모바일 레이아웃과 D존 확대 동작 확인. 테스트용 상태는 운영 DB에 포함하지 않는다. WebMCP 문서 도구는 기능 감지로 등록하며, 현재 미리보기 브라우저에서 노출되지 않아 실행 검증은 미완료.
